# 中证1000策略助手 PWA V1.0.3

## 运行
必须通过 HTTP/HTTPS 访问，Service Worker 不能长期依赖 `file://`。

本地测试可在本目录运行：

```bash
python -m http.server 8080
```

然后浏览器打开：

`http://localhost:8080`

手机正式安装时应部署到 HTTPS 静态站点。

## 数据源
- 2026 A股交易日历本地JSON
- 中证1000公开历史行情由 GitHub Actions 更新到同源 `data/csi1000-history.json`
- 三因素在设备本地计算
- 缺少可靠年度交易日历时不猜测、不自动补录
- 行情超过7个交易日或无法可靠计算新鲜度时，禁止150/200/300元市场加码
