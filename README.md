# 中证1000策略助手 PWA V1.0.6

## 运行
必须通过 HTTP/HTTPS 访问，Service Worker 不能长期依赖 `file://`。

本地测试可在本目录运行：

```bash
python -m http.server 8080
```

然后浏览器打开：

`http://localhost:8080`

手机正式安装时应部署到 HTTPS 静态站点。

## 数据源
- 2026 A股交易日历本地JSON
- 手动更新优先直连东方财富公开行情；失败时回退到 GitHub 同源静态文件，再回退到本地缓存
- GitHub Actions 继续更新 `data/csi1000-history.json`，作为自动更新与回退通道
- 三因素在设备本地计算
- 缺少可靠年度交易日历时不猜测、不自动补录
- A股时间状态统一按 Asia/Shanghai 判断；盘中及开盘前沿用上一完整交易日收盘，不暂停建议
- 收盘至18:30显示“等待今日完整收盘数据”并保留已有建议
- 北京时间交易日15:00后允许接纳当日完整日K；18:30前缺失属于同步等待窗口，不判定延迟
- 缺少应有收盘数据时仅给出基础规则建议；行情超过7个交易日或无法可靠计算新鲜度时，同样禁止市场加码
